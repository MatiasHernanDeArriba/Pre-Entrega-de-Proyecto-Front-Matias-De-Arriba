# Cebador

Sitio web de un ecommerce de yerba, mates y bombillas. Proyecto de práctica de la pre-entrega (Clase 8, Git y GitHub).

## Qué incluye

- Estructura semántica con `header`, `nav`, `main`, `section` y `footer`.
- Sección **Productos** con cards en Flexbox.
- Sección **Reseñas** con CSS Grid.
- Sección **Contacto** con formulario de Formspree y diseño responsivo con media queries.
- Mapa embebido con un `iframe` e imágenes SVG de los productos.
- Tipografías de Google Fonts y estilos en `styles.css`.

## Sitio publicado

(https://matiashernandearriba.github.io/Pre-Entrega-de-Proyecto-Front-Matias-De-Arriba/)

## Cómo correrlo en local

Abrí `index.html` en el navegador. No necesita instalar nada.

## Tecnologías

HTML5, CSS3, Formspree y GitHub Pages.
